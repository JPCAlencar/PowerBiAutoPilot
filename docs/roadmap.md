# Próximos marcos

## P0 — testar o motor da Microsoft
Criar manualmente PBIP/PBIR pequeno, instalar skills oficiais, rodar validação, abrir Desktop, screenshot e corrigir; registrar versão e comandos. Não temos essa verificação neste protótipo.

## P1 — provar análise inteligente (esta versão)
Entrada local CSV/XLSX → perfil + detecção de domínio + pré-requisitos Gantt + grade sem colisões. Critério: suíte unitária passa e plano gera alertas quando faltam datas.

## P2 — primeiro dashboard ponta a ponta
Uma base sintética de projetos, com medidas DAX, Power Query, Gantt disponível, KPIs, filtro e entrega PBIP. Critério: abre, dados corretos, todos os visuais renderizados e screenshots revisados.

## P3 — receitas e design
Adicionar finanças, faturamento e logística, com variações de grids, legibilidade, responsividade e componentes de identidade visual.

## P4 — robustez e distribuição
Analisar múltiplas tabelas, regras customizadas, logs/retries, isolamento de permissões, catálogo de erros, integração MCP, testes de regressão visual, empacotamento para diferentes agentes.
